I used a single-page application (SPA) approach where the navbar, footer, and all page content exist within one HTML file, with JavaScript controlling which page section is visible. This eliminates the need to copy-paste the same navigation and footer code across multiple files, as they're defined once and remain persistently rendered in the DOM. The navbar and footer stay outside the dynamic page container, so they never get re-rendered or reloaded when switching between pages—only the content inside the container changes. This approach ensures consistency automatically, reduces maintenance overhead, and provides a smoother user experience since the navigation and footer are always present and never flicker during page transitions.
